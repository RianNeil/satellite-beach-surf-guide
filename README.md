# satellite-beach-surf-guide
Modern surf-inspired website about Satellite Beach, Cocoa Beach, and Melbourne surfing culture and spots. Built and evolved by a multi-agent Grok Bot team.

## Tests

Ability scores, daylight peaks, the offshore wind-cell check, and NWS rip parsing:

```bash
node --test scoring/surf-score.test.js
```

The same command runs in GitHub Actions on pull requests.
